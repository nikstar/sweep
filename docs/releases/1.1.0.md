Choose **Sweep → Check for Updates…** to check for a new release and install it
from the app. To have Sweep check periodically, turn on **Automatically check
for updates** in Settings.

**Upgrading from Sweep 1.0?** Download **Sweep-1.1.0-macOS-universal.zip**,
unzip it, quit Sweep, and replace **Sweep.app** in **Applications**. This
one-time manual update adds the in-app updater.

Requires macOS 15 or later on Apple silicon or Intel.
