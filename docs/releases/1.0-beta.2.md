Sweep is a native BitTorrent client for macOS, with a Rust rqbit engine and a compact, classic-client interface.

This first public beta includes magnet and torrent-file support, per-file selection,
tracker and peer inspection, session restoration, and network health diagnostics.

Requires macOS 15 or later. The universal build supports Apple Silicon and Intel.
Download the ZIP, move Sweep to Applications, and open it. The app is signed with
Nikita Starshinov's personal Developer ID and notarized by Apple.

This is early software. Network behavior varies across VPN configurations;
DHT/uTP connectivity diagnostics and interaction polish are still in progress.
